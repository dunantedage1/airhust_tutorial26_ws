# 2026 级梯队培训 · 文档目录

这套材料分成四个板块。板块一、二已经写完，板块三先补了视觉方向，剩下的由队友接着写。

## 板块一：环境与工程规范

先把机器搭起来，再知道代码该往哪放。

1. [仿真环境配置](01_simulation_setup.md)：Ubuntu 上从零装 ROS + PX4 + Gazebo，跑通仓库地图，加下视相机
2. [ROS 包的标准结构](02_ros_package_structure.md)：`src`、`include`、`scripts`、`launch` 各放什么，怎么建包
3. [package.xml 和 CMakeLists.txt](03_cmake_and_package_xml.md)：两个文件逐行讲，依赖为什么写三处
4. [用 rosrun 和 roslaunch 跑节点](04_run_your_node.md)：master 是什么，launch 怎么写，出问题怎么看

## 板块二：视觉基础

五个完形填空，全部离线跑，不碰 ROS。代码和环境说明在 [`lab_vision/`](../板块2%20函数原型与静态调用/lab_vision/README.md)。

顺序是颜色、二维码、AprilTag、OCR、YOLO。前三个只依赖 OpenCV，第四个用 tesseract，第五个用 ultralytics 做推理。

## 板块三：仿真单元测试

起飞、定点、下视拍照、识别、降落，五关。ROS 相关代码全部自己写，识别部分可以从板块二抄。题目、过关线、ROS 话题与图像订阅的写法都在 [板块三 README](../板块3%20仿真单元测试/README.md) 里。

这一关开始分方向：视觉、避障、点云。三条线的题目不一样，带的人也不一样。

## 板块四：组队大任务

三人一队，任务书、地图和组队说明在 [板块四](../板块4%20组队完成大项目/README.md)。

## 关于这套文档

板块一、二是老成员写的，板块三先补了视觉方向，避障和点云两条线由各自负责人补。板块四已经补上组队说明与任务书。补的时候沿用同样的目录结构：一篇文档讲一件事，图放 `image/`，命令能直接复制。

文档里的路径都以仓库根目录为准。`~/airhust_tutorial_ws` 是去年仓库的位置，今年换了名字的话，读到路径自己替换一下。
